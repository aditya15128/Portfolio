Phishing URL Detector

Solo project · In progress

A machine learning model that tells whether a URL is likely to be phishing. It reaches about 93.9% test accuracy.

  • Python
  • pandas
  • scikit-learn
  • Streamlit

How it works: A Decision Tree is trained on the UCI Phishing Websites dataset, which describes each URL with features like its length, use of special characters and domain details.

What’s next: I’m building a Streamlit app so anyone can paste a link and see the result.

ATC Voice Simulator: Interruptible Training Mode

Team project · DataForge Hackathon 2026

A voice-based air traffic control trainer where the AI speaker can be interrupted mid-sentence, like real radio traffic.

  • asyncio
  • LiveKit
  • Deepgram
  • OpenAI GPT-4o
  • Rime

How it works: Speech is turned into text in real time, a language model replies, and a text-to-speech voice speaks the answer. The system can stop speaking the moment the trainee talks.
